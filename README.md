# Percy-Work

Percy-Work records execution: what was delivered, what should happen next, and what dependency prevents it. The full [execution contract](PERCY_WORK_README.md) remains authoritative.

Forty-two reviewed venue/track routes have been mapped to project evidence and remaining requirements.** The follow-up adds manuscript drafts, short abstracts, presentation PDFs, a working demonstration and movie, exact mathematical checks, and measured technical notes. The [restricted conference index](https://github.com/THE-BU1LD/org-infra-/blob/d732011254d071e2d2d3b1bb5866187c16c30dba/conferences/index.json) contains the pinned project evidence, verification records and route details. Repository access is required. This public execution record includes aggregate progress and dependency types; scientific results and source evidence remain in their canonical locations.

## Resume work

1. Read the [master queue](MASTER_QUEUE.md) and [blocker records](BLOCKERS.md).
2. Open the canonical location linked for the selected task.
3. Admit newly available evidence or decisions before changing its status.
4. Execute the next unblocked action, verify it, and append a factual [run log](RUN_LOG.md).

The completed follow-up packages remain in open, unmerged draft PRs; their new conference materials remain unsubmitted. The current queue has no substantial task in progress. Source recovery is **BLOCKED**; data access, independent review and external venue decisions are **WAITING_EXTERNAL**. A dependency becoming available is a reason to resume its task, not evidence that the task is finished.
